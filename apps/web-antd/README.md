# 讲座管理系统前端

本项目是基于Ruoyi-Vue-Plus框架开发的讲座管理系统前端部分，采用Vue 3 + TypeScript + Ant Design Vue开发。

## 功能特性

系统实现了以下主要功能：

### 1. 讲座管理
- 讲座信息的增删改查
- 讲座状态管理（未开始、进行中、已结束）
- 讲座详情展示

### 2. 场地管理
- 场地信息的增删改查
- 场地容量和设备管理
- 场地预约状态显示

### 3. 讲座预约
- 用户预约讲座
- 预约取消
- 预约状态查询

### 4. 讲座签到
- 多种签到方式支持（二维码签到、签到码签到）
- 签到状态显示
- 签到统计分析

### 5. 讲座反馈
- 用户提交讲座反馈
- 反馈内容星级评价
- 匿名反馈选项
- 反馈数据统计分析

### 6. 智能推荐
- 基于用户兴趣的讲座推荐
- 相似讲座推荐
- 热门讲座推荐
- 用户行为分析

### 7. 智能排期
- 场地自动匹配
- 冲突检测
- 设备需求匹配
- 讲座时间智能安排

### 8. 统计分析
- 讲座热度分析
- 用户参与度分析
- 签到率统计
- 反馈评分分析

### 9. 通知系统
- 讲座提醒
- 签到提醒
- 反馈提醒
- 通知状态管理

### 10. 推荐引擎管理
- 推荐算法配置
- 推荐权重调整
- 推荐多样性设置
- 用户兴趣分析

## 技术栈

- Vue 3：前端框架
- TypeScript：类型安全的JavaScript超集
- Ant Design Vue：UI组件库
- Pinia：状态管理
- Vue Router：路由管理
- Axios：HTTP请求

## 特色功能详解

### 智能推荐系统

系统采用基于用户行为的协同过滤算法，结合内容特征分析，为用户提供个性化的讲座推荐：

1. **用户行为追踪**：记录用户浏览、预约、签到、评价等行为
2. **兴趣特征提取**：基于用户行为提取兴趣特征
3. **相似度计算**：计算讲座之间的相似度
4. **个性化推荐**：根据用户特征和讲座特征提供推荐

### 智能排期系统

为管理员提供智能化的讲座排期功能：

1. **需求匹配**：根据讲座需求（设备、容量等）匹配合适场地
2. **冲突检测**：自动检测时间冲突
3. **优化排期**：根据场地利用率、讲座重要性等因素优化排期方案

### 多样化签到系统

支持多种签到方式，提升用户体验：

1. **二维码签到**：生成唯一二维码，支持扫码签到
2. **签到码签到**：提供数字签到码
3. **位置验证**：支持位置信息验证
4. **签到统计**：实时统计签到率，提供数据分析
